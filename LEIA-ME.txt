APLICAR
1. Extraia este ZIP e copie correcao-modais.patch para a pasta do repositório Lazer-Sport.
2. Abra o PowerShell nessa pasta e execute:

   git apply --check .\correcao-modais.patch

3. Somente se a verificação terminar sem erros, execute:

   git apply .\correcao-modais.patch

O primeiro comando não altera arquivos. Se indicar conflito, não force: a versão local difere da base e é necessário ajustar o patch.
O patch não envia mudanças ao GitHub e não publica o site.
