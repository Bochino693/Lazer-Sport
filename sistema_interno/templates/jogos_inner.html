Jogo de console ou de fliperama. Em “Cadastrar jogo novo”, arraste todos os arquivos do jogo de uma vez — o .cue com todos os .bin (Track 01, Track 02…), os discos de um jogo de vários discos, a BIOS se o console pedir. O painel lê o .cue, diz o nome de cada arquivo que faltar, reconhece o sistema pelo conteúdo e sugere o formato da tela e os controles. Rodam no site: {% for s in emulador.sistemas %}{% if s.ligado %}{{ s.nome }}{% if not forloop.last %}, {% endif %}{% endif %}{% endfor %}. {% if emulador.modo == "grande" %}Os arquivos vão direto do seu navegador para o armazenamento de jogos grandes (até {{ emulador.limite_mb }} MB cada).{% else %}Disco grande (PS1 tem 300–700 MB) vai em pedaços de {{ emulador.pedaco_mb }} MB, direto do seu navegador para o armazenamento; o jogo junta os pedaços na hora de jogar.{% endif %}
Jogo que só tem versão para computador. Cadastre o jogo e guarde o .exe (ou um .zip com a pasta do jogo) em "Versão para computador". O navegador não roda .exe, então o jogo fica guardado, sem aparecer no site, até ganhar a versão de navegador: o painel reconhece o motor (Godot, Unity...) e diz o caminho mais curto; a partir desse arquivo dá para portar o jogo para o site, como os oficiais. Nada disso vai para o público, e o arquivo não tem download para visitantes.
Sobre o APK. Ele só é pedido ao cadastrar um jogo pelo painel, é opcional, e fica guardado sem link para ninguém — a não ser que "Deixar baixar" esteja marcado. Os jogos oficiais não têm APK no site: o material deles (capa, pôster, textos) é o do simulador, e o jogo de verdade fica na máquina.
