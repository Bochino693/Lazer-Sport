{% comment %} O AVISO DE EXCLUSÃO FORÇADA. Some para quase todo mundo: as regras normais só deixam apagar o que é seguro apagar, e nesses casos não há o que avisar. Ele aparece para o superusuário sobre um registro que as regras protegem -- proposta já enviada, O.S. concluída, cliente com histórico. Aí a pessoa precisa saber que está passando por cima de uma proteção, e não fazendo uma exclusão comum. O JavaScript da tela liga isso pelo atributo `data-protegido` do botão que abriu a janela. {% endcomment %}
Isto não é um rascunho. As regras normais protegem este registro por ele já fazer parte do histórico. Você pode excluir mesmo assim, e a exclusão vai ficar registrada com o seu nome.

Quem quiser explicar, explica; quem não quiser, o registro guarda o resto de qualquer jeito: o quê, quem e quando. {% endcomment %} Pode usar letras maiúsculas ou minúsculas.
